# Line Following Robot with Obstacle Avoidance

An autonomous robot that follows a black line track and avoids obstacles in real time.

## Components Used
- Arduino Uno
- IR Sensors (x2)
- Ultrasonic Sensor (HC-SR04)
- L298N Motor Driver
- DC Motors (x2)
- 9V Battery

## How It Works
- IR sensors detect the black line on the surface
- Robot follows the line automatically
- Ultrasonic sensor detects obstacles ahead
- Robot stops or turns to avoid collision

## Skills Used
- C++ / Arduino Programming
- Embedded Systems
- PWM Motor Control
